# Origin 绘图参数

在主窗口顶部点击“Origin 绘图参数…”。源码版也可以双击 `Origin-Settings.cmd` 单独打开。

## 怎么填

先在模型结果列表中确认要绘制的结果，再填写对应的 Tag 和 X/Y 列。绘图设置选中的结果必须与本次提取的结果一致。

参数窗口分为五页：

- **曲线与数据**：结果 Tag、数据列、图型，以及各条曲线的颜色、线型和图例文字。
- **坐标轴**：标题、单位、范围、刻度间隔及线性/对数坐标。
- **字体、图例与布局**：字体、字号、图例位置和图层边距。
- **尺寸与导出**：图片宽高、DPI、文件格式、透明背景和输出位置。
- **数据处理**：无效值清理、排序、平滑和插值。

X/Y 列填写去掉单位后的表头名称。单位文字只用于标注，不会换算数据。对数坐标要求所选数据大于零。

## 保存设置

点击保存后，程序会检查参数。参数不合法时会提示原因，不覆盖原配置；保存成功后，上一份配置保留为 `config.toml.ui-backup`。

下次提取会读取新设置，不需要重启程序。EXE 的配置位于 `%LOCALAPPDATA%\COMSOLOrigin\config.toml`，源码版位于项目目录。

## 开发检查

运行 `python scripts/verify_settings_ui.py` 可以检查页签、设置保存和主窗口按钮。截图输出到 `output/settings_preview/`。

这个脚本不启动 COMSOL 或 Origin，只检查界面和配置读写。实际提取、绘图与导出需要另做检查。
